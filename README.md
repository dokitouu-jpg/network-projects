# Network Engineering Portfolio

A collection of hands-on networking projects documenting the design, implementation, verification, and troubleshooting of enterprise network technologies.

---

## Overview

This repository serves as a portfolio of networking laboratories and technical documentation covering switching, routing, network services, and infrastructure fundamentals.

Each project follows a consistent engineering methodology to ensure clarity, reproducibility, and structured technical documentation.

Documentation includes:

* Objectives
* Technical Concepts
* Network Topology
* Addressing Plan
* Configuration
* Verification & Testing
* Troubleshooting
* Lessons Learned
* References
